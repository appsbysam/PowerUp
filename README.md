# PowerUp

Mobile-first job organiser for an electrician.

## Stack
- HTML / CSS / JavaScript
- Supabase Auth + Postgres
- GitHub Pages ready
- Progressive Web App ready

## Current features
- Email/password authentication
- Create, edit and delete jobs
- Status and priority tracking
- Scheduling date, start time and estimated duration
- Customer, address, suburb and notes
- Today / Unscheduled / Completed quick filters
- Search and status filtering
- RLS-protected Supabase data per user
- Web app manifest and service worker

Version: 0.1.0
